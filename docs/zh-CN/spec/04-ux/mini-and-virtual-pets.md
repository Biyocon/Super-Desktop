# Mini 与虚拟宠物（Super-Desktop）

## 用户流程

Settings 的 Preferences 下提供可搜索的 Mini and virtual pets 页面，显示当前选择、真实动画预览、None、Hassan、用户导入项以及刷新、导入和 AI 创建入口。选择由 host-core 持久化；保存失败可见且保留原选择。None 在重启后保持，不显示欢迎页人物，但保留 Mini 控件。

Hassan 由所有者提供并独立打包，不依赖安装 `.codex`。不复制其他 ChatGPT 内置宠物。用户拥有的 `pet.json` 与 `spritesheet.webp/png` 通过原生选择器进入结构检查、完整解码、预览及显式安装流程。包不能提供脚本、URL 或文件系统权限。预览后源指纹变化必须重新预览；重复 ID 被拒绝，已有宠物不被覆盖。

## 图集契约

每格为 192x208，共八列。V1 为九行（1536x1872），v2 为十一行（1536x2288）。缺少 `spriteVersionNumber` 视为 v1。标准动作及逐帧时间定义在 `packages/shared/src/pets.ts`，以提供的图集参考为依据。

V2 的第 9/10 行包含十六个顺时针方向，以屏幕上方开始；指针死区使用 idle。不得旋转整个精灵来模拟视线。减少动态效果始终显示 idle 第一帧。隐藏或卸载时释放动画监听器和帧调度。

## Mini

Mini 是唯一的透明、可拖动、沙箱化且无任务栏入口的窗口。显示/隐藏、位置、缩放、置顶和指针跟随由主机拥有并持久化。新配置默认隐藏。保存的位置被限制在当前显示器工作区域；显示、聚焦或重新绑定不能创建重复窗口。

快捷键使用现有可配置注册表，初始为 Ctrl+Alt+P，macOS 为 Cmd+Alt+P；报告实际注册冲突，不硬编码截图中的 Windows 组合键。指针跟随仅观察 Mini 内部，不进行全局指针轮询。

控件提供新任务、听写、宠物设置和隐藏。新任务复用现有会话创建；Mini 不运行 agent，也不批准请求。活动状态仅来自实际选中会话，而不是任意最近后台任务。等待、错误、计划审阅和运行状态由真实应用状态投影，不伪造进度。重新加载或切换会话使过期回调失效。

## 听写

复用现有语音输入能力，不增加第二套语音引擎。在 Settings > Mini and virtual pets > Dictation provider 中选择现有已启用供应商、受支持的转写协议与模型 ID，然后 Save。None 禁用转写但不删除语音合成设置。密钥仍由现有供应商存储管理；旧 Voice 页面不是此能力的配置入口。只修改模型时保留兼容的自定义 `path`/`extra` 字段。

录音需要麦克风权限和可见录音状态。完成的转写成为草稿，保留现有草稿文本，绝不自动提交。取消、切换会话或关闭不能把迟到结果插入另一会话。语音不可用时显示真实配置入口，不伪造录音成功。测试未获明确授权时不得调用实际付费语音或模型。

Mini 仅在显式签发的 capture token 有效期间允许音频。录音最多 60 秒 / 25 MB。隐藏、关闭、renderer 重新加载、语音不可用以及选中会话变化均使录音和结果身份失效。转写后删除临时会话音频。结果在 Mini 内保持可编辑，直到所有者选择 Open draft；保留输入框已有文本和附件。取消无法撤销已经发出的供应商请求，但会丢弃迟到结果。

## AI 创建

AI 创建收集名称和描述，说明供应商使用及费用，并在确认后启动正常且有边界的 agent 任务。复用现有图像生成能力和宠物创建指导，不使用 ChatGPT 私有 Pets MCP。进度、失败和取消在该任务的正常 transcript 中可见。

目标输出为完整 v2 包、动作预览与质量证据，不是静态吉祥物或回复中虚构的文件名。所有者审阅后，通过同一验证、预览和确认流程导入实际包；成功文字本身不能安装宠物。无效按钮或纯导入不能宣称完成 AI 生成。

## 验证

覆盖缺省/已有配置重启、有效及无效导入、过期预览、重复 ID、源文件保留、明暗主题、None、所有动作行和视线方向、减少动态效果、监听器清理、原生窗口生命周期、发送者授权、快捷键冲突、选中会话状态、仅草稿听写和确认后的 AI 任务入口。隔离 Electron 验收不得把所有者正在运行的应用当作 fixture。未进行的付费供应商验收必须明确说明。

先构建候选 shared/desktop 与 host，再运行 `node scripts/e2e-mini-pets.mjs`。它使用隔离的数据、配置及 agent 路径和真实应用；原生选择器与外部媒体捕获为 fixture，语音和 agent 请求使用 loopback HTTP。它验证配置、编辑草稿后追加、不自动发送、音频清理、费用确认及正常 transcript 交付，不使用真实麦克风或付费服务。组件和服务测试覆盖过期结果、动画与取消。

Windows 上 Electron `nativeImage` 不能直接解码 WebP。临时沙箱 Chromium renderer 在没有 preload、网络或权限的情况下解码。签发五分钟安装 token 之前检查完整位图尺寸、透明度和每个必需格中的可见内容。确认必须是单次、所有者绑定并重新校验源指纹。
